# Privacy Policy: Hide Blocked Messages for Discord

_Last updated: November 26, 2026_

**Hide Blocked Messages for Discord does not collect, store, or share any
personal data.**

- **What it does:** it hides messages from people you've blocked on
  discord.com by changing how the page looks.
- **What it stores:** only the "fixes" you create with the **Fix it** button.
  A fix is the name of a part of Discord's page (for example
  `blockedSystemMessage`). It never contains messages, usernames, or anything
  about you.
- **Where it's stored:** in Chrome's own extension storage. If you use Chrome
  sync, Chrome may sync your fixes between your own devices. The developer
  can't see them.
- **What it sends:** nothing. The extension makes no network requests, has no
  analytics, and doesn't use any outside servers.
- **Where it runs:** only on `discord.com`, `ptb.discord.com`, and
  `canary.discord.com`.

You can delete all stored fixes at any time with **Undo my fixes**, or by
removing the extension.

Questions? Open an issue on this project's GitHub page.
